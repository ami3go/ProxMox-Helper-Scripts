# Code of Conduct

Be respectful, technical, and constructive.

- Discuss ideas and code rather than personal characteristics.
- Provide reproducible evidence for defects and compatibility claims.
- Avoid publishing credentials, private logs, or sensitive infrastructure details.
- Accept maintainer decisions on scope, security defaults, and release readiness.

Harassment, discrimination, threats, and deliberate disruption are not acceptable. Maintainers may edit or remove content and restrict participation when necessary to protect contributors and users.
